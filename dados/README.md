# Dados do Monitor Serial

Salve em `dados/bruto` o texto bruto copiado do Monitor Serial do Wokwi, por
exemplo em `dados/bruto/monitor_serial.txt`. O importador procura somente as linhas que
começam com `ROOTSO_CSV;`, portanto mensagens de inicialização podem permanecer
no mesmo arquivo.

O arquivo bruto não deve conter senhas ou outras credenciais.
